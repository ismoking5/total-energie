# Total Énergie

Application mobile-first d'investissement basée sur React + TypeScript + Vite + Tailwind avec Supabase.

## Démarrage

```bash
npm install
npm run dev
```

## Variables d'environnement

Copier `.env.example` en `.env` si vous souhaitez utiliser des variables locales.

## Fonctionnalités principales

- inscription et connexion
- popup d'information à chaque ouverture
- dépôt mobile money avec confirmation post-paiement
- retrait avec frais automatiques
- validation manuelle admin
- historique des dépôts et retraits
- produits d'investissement 180 jours
- backoffice avec gestion des demandes, produits et réglages
